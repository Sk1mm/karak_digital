# Development Workflow

## Полный цикл реализации story

```
Story (Ready)
    │
    ▼
/dev-story [path]                ← Claude пишет код + тесты через субагентов
    │
    ▼
/code-review [files]             ← ревью кода
    │
    ▼
/playtest-story                  ← плейтест и ручная проверка
    │
    ▼
/story-done [path]               ← закрытие story, обновление документов
    │
    ▼  (только если нужна работа в Godot-редакторе)
/create-task → tasks/[epic]-[slug]-godot-editor.md
```

---

## Что делает Claude самостоятельно

| Что | Где | Когда |
|-----|-----|-------|
| GDScript-код | `scenes/`, `autoloads/`, `src/` | В рамках /dev-story |
| Тесты | `tests/unit/`, `tests/integration/` | Параллельно с кодом в /dev-story |
| Обновление документов | `docs/`, `production/` | В /story-done |
| Task-файл для редактора | `tasks/` | Только при наличии Godot-редактор работ |

Код и тесты — **без запроса подтверждения**. Дизайн-документы (GDD, ADR) — с показом черновика.

---

## Что делает пользователь в Godot-редакторе

Только то, что нельзя сделать кодом:

- Настройка TileSet (текстура, атлас, тайлы)
- Привязка скрипта к ноде в Scene Tree
- @export поля в Inspector (назначение ресурсов, ссылок на ноды)
- Добавление Autoload в Project Settings
- Создание .tscn сцены через меню редактора

Для каждого из этих случаев Claude создаёт `tasks/[epic]-[slug]-godot-editor.md`
с пошаговыми инструкциями — **только шаги в редакторе, без кода**.

---

## /create-task — только для Godot-редактора

`/create-task` создаёт **инструкцию для пользователя** по работе в Godot-редакторе.
Код в task-файл не включается — его пишет `/dev-story` напрямую в `.gd`-файлы.

**Формат task-файла:**
- Пронумерованные шаги (1, 2, 3...)
- Каждый шаг = одно конкретное действие: «открой X → нажми Y → введи Z»
- Явные пути: `Inspector → TileSet → New TileSet`
- Пункт проверки после каждого шага: «ты должен видеть...»
- Раздел «Godot-редактор» — если работы нет, написать явно «Ничего не нужно»

**Не содержит:** GDScript-код — его пишет `/dev-story`.

---

## Тесты запускает пользователь вручную

Claude никогда не запускает тесты через Bash.
После `/dev-story` статус тестов = NOT RUN до момента ручного запуска в Godot Editor.

## Порядок commits

После каждой завершённой задачи (есть изменённые файлы):

```bash
git add [конкретные файлы]
git commit -m "feat/chore/test: описание"
```

Не использовать `git add -A` — только конкретные файлы.
